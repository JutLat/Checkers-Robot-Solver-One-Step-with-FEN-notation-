This is the current solver I created with the help of Omar.
Currently it imports the proper board type and an engine for the robot to make moves.
Next main.py can be run with a Forsyth–Edwards Notation (FEN).
EX: "W:W21-32:B1-12" The first "W" means white to move, the second array.

This notation is used to create the board with all given moves, numbers from 1-32 (since white squares cannot be filled by pieces)
